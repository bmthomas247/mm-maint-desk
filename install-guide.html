🧰What to bring

  • Hub, Z-Wave stick, USB extension cable.
  • An Ethernet (network) cable, 6 ft or longer. The hub plugs into the router with it - don't count on finding one at the home.
  • Fresh AA batteries for every lock. The home's master code (on the Install page - the app makes one for brand-new homes).
  • Key box + the spare key. Most key boxes get code 1358.
  • A bag for the owner's old locks, thermostat and Brivo parts. Phone charged - you'll take photos.

📏Distances at a glance

3 ft+Z-Wave stick away from the hub and the router (use the USB extension cable)
≤ 2 wallsbetween the stick and each door lock - or 1 floor. More than that: add a repeater
3–4 barssignal every lock needs on the Install page (−75 dBm or better)
6 ft+noise sensor away from TVs, speakers and the fridge / dishwasher

Walls and floors matter more than feet. Brick, stone, concrete, mirrors, metal doors and appliances block the signal the most. The Install page's signal bars are the real test - always check them.

📦1 · Hub (gateway) - Home Assistant Green

  • Next to the router: power + the Ethernet cable you brought into the router. The hub never uses Wi-Fi.
  • Take a photo of where it is and type the spot on the Install page, so the next tech can find it.
  • Owner closet / utility room, as central in the home as the router allows. On a shelf, not the floor. Not inside a metal cabinet or behind the water heater / furnace.
  • Wait for the Hub light on the Install page to go green before pairing anything.

📡2 · Z-Wave stick (the antenna)

  • Always on the USB extension cable - never plugged straight into the hub (it picks up interference).
  • At least 3 ft from the hub and router, standing up, as high and central as the cable reaches. Tape or clip it in place.
  • Put it in its final spot before pairing, then don't move it. Moving it later breaks the routes to the doors.

🔒3 · Door locks

  • Pair the closest door first, then work outward.
  • What the keypad buttons do (tap Start pairing on the phone first): master code = unlocks the lock's settings · ⚙ (gear; # on some keypads) = enter / confirm · 7 = Network module (the lock's wireless part) · 1 = Join network (pair to our hub) · 3 = Leave network (take it off Brivo). So pairing is: master code ⚙ 7 ⚙ 1 ⚙. Taking it off Brivo: master code ⚙ 7 ⚙ 3 ⚙.
  • Brand-new lock: put the batteries in - it asks for a master code. Press ⚙, type the home's master code, press ⚙.
  • 7 does nothing? The wireless module is loose, or the lock has no master code yet.
  • Pair at the door with the lock in its final place (door closed when you test).
  • Each lock needs 3 bars or more and few dropped messages on the Install page. Press Ping - it should answer in under a second.
  • 1–2 bars, a garage / basement door, or more than 2 walls or 1 floor away: plug a Z-Wave plug-in repeater into an outlet about halfway between the stick and the door, then press Rebuild routes once.
  • Battery devices (locks, battery sensors) don't pass the signal on. Plugged-in / wired devices do - that's what a repeater is.

🌡️4 · Thermostats

⚡ Changing out a thermostat? Turn OFF the power to the HVAC system first - the furnace / air-handler switch or its breaker. Check the old thermostat's screen is dead before touching any wires. Take a photo of the wiring before you disconnect it.

  • Stay where they are on the wall - don't move them for signal.
  • Wired (C-wire) Z-Wave thermostats also act as repeaters, so pair them before the farthest doors - they can help a weak lock.
  • Same 3-bars rule. Leak sensors: under the water heater / sinks; they're battery, so same rule.

🔊5 · Noise sensor (Atom Echo)

  • Set it up at the office first on the noise sensor setup page with this home's Wi-Fi.
  • Main living area, plugged into a USB-C charger, about chest height (a shelf is great). Not in a bedroom.
  • At least 6 ft from the TV, speakers, fridge, dishwasher and HVAC vents - they make it read loud when nobody's there.
  • It uses Wi-Fi, not Z-Wave: keep it where the home's Wi-Fi is strong. It shows on the Install page within a few minutes.

✅Before you leave

  • Install page header says 🟢 Everything is connected.
  • 🔥 Heat test passed: tap Start heat test, wait a few minutes, feel warm air at a vent, tap Yes. No heat = don't leave - call Chris.
  • Every door: 3+ bars, Ping answers, the test code opened it.
  • Press Rebuild routes once after the last device (not again and again - it slows the doors for a few minutes).
  • Nothing moved after pairing: stick, repeaters, hub.
  • Key box hung with the spare key, code set (usually 1358) - photo + which keys are in it saved on the Install page.
  • Owner's old hardware bagged and put in the owner closet or furnace room - never where guests can find it. Photo saved.
  • TVs: coming soon - nothing to set up yet.
  • Anything that doesn't apply to this home: tap N/A on that step.

⚠️Signal problems

  • Weak lock: move a repeater (not the stick) closer to that door → Rebuild routes → check bars.
  • Everything red at once: hub power or router cable, then the stick's extension cable.
  • Still stuck: call Brandon from the home - don't leave a door that isn't green.

Sources for the stick rules: Home Assistant Z-Wave docs (extension cable, don't move the adapter, rebuild routes sparingly) and Vesternet (only mains-powered devices repeat). Distances are our starting rules - the signal bars decide.
